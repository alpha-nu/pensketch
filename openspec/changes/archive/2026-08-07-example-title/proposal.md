# Proposal: example-title

> A requirement whose heading counts, over a set that grows.

## Why

`atm-example` added a fourth example folder and updated the requirement body
to name it. The heading kept its original wording, because a modified
requirement is identified by its heading and cannot change it — so the spec
now reads "Three runnable examples" over a paragraph naming four.

A count in a heading is a fact with a short life. Removing it costs nothing
and stops the next example folder from reopening this.

## What changes

- The requirement is renamed to drop the count. Its body is untouched.

## Impact

- **Affected specs**: `documentation-and-examples`
- **Affected code**: none
